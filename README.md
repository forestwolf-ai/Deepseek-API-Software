#deep seek API软件
这个由计算机编程语言python构建的程序可以使用深度求索的API，但是仅适用于deepseek！仅限中文版！

运行依赖库如下：

pip install customtkinter cryptography bcrypt openai pyperclip pillow pystray flask flask-socketio flask-cors pyttsx3 SpeechRecognition reportlab

1.0版本更新：有深色模式和浅色模式，要有登录和注册的功能，能够加密保存API密钥，登录和注册所得的用户信息要加密保存，允许用户自由开启深度思考模式与智能搜索，接收量无限，如果检测到代码的时候自动生成到一个框里，方便用户复制粘贴和下载，用户的聊天记录都可以保存在本地，然后用户打开这些聊天记录的时候，用户可以继续与大模型进行交谈，允许用户新建对话，而且这些对话都有相应的名字。
