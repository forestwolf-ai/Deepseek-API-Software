## CLI程序简介

# DeepSeek Chat v1.9.0 —— 功能完备的多厂商 AI 对话终端 & 网页版

DeepSeek Chat 是一个 **全功能、跨平台、近乎无限上下文** 的 AI 对话工具。它同时提供 **命令行（CLI）** 和 **内置网页（Web UI）** 两种交互方式，支持 **DeepSeek、OpenAI、Moonshot（Kimi）、智谱 GLM、通义千问（阿里百炼）、Ollama（本地模型）、OpenRouter** 等多个大模型厂商，并实现了 **会话管理、自动上下文压缩、消息编辑/删除、导入/导出、提示词模板、思考链、硬件自适应加速** 等企业级特性。  
整个程序仅用一个 Python 文件（`chat2.py`）即可运行，无需复杂的安装部署，适合个人开发者、团队协作、本地实验和轻量级生产使用。

---

## ✨ 核心特性一览

- **多厂商无缝切换** —— 支持 DeepSeek、OpenAI、Kimi、智谱、通义、Ollama、OpenRouter，使用 OpenAI 兼容接口，一键切换厂商与模型。
- **会话管理** —— 支持多会话独立存储（命名、切换、复制、重命名、删除），历史存档自动保存到 `chat_history.json`。
- **近乎无限上下文** —— 自动裁剪机制：当上下文接近窗口上限时，将早期对话压缩为摘要保留（或直接裁剪），支持 100 万 token 的大窗口模型（DeepSeek V4）。
- **思考链（Reasoning）** —— 对支持思考链的厂商（如 DeepSeek），可开启思考模式并设置思考等级（low/medium/high/max），在回复前展示模型推理过程。
- **硬件自适应调优** —— 自动检测 CPU 核数、内存大小、磁盘速度、GPU 与显存，动态调整连接池、网页并发线程、自动保存频率，弱机（低配电脑）自动降级保证流畅，强机充分压榨性能。
- **双界面** —— 命令行（CLI）适合自动化与快速操作；内置网页版（Web UI）提供可视化界面，支持流式输出、消息编辑/删除、搜索、会话切换、设置面板，且两者共用同一份对话历史和配置。
- **完整的消息操作** —— 编辑/删除已发送的用户消息，撤销最后一轮对话（`undo`），重新生成回复（`redo`），搜索对话历史（`find`），跨会话搜索（`findall`）。
- **导入/导出** —— 对话可导出为 Markdown 或 JSON 格式，也能从导出的 JSON/Markdown 文件导入（替换或追加）。
- **提示词模板库** —— 内置翻译、代码审查、内容总结、写作润色等模板，可保存、应用、删除自定义模板。
- **用量统计与成本估算** —— 累计输入/输出 token 数，按可配置单价估算成本。
- **系统体检与基准测试** —— `health` 命令检查 Python 兼容性、硬件、磁盘、网络、配置；`bench` 运行 token 估算速度、JSON 序列化速度、磁盘写速度测试。
- **电源管理** —— 检测电池供电状态，自动进入低功耗模式（降低轮询与保存频率），延长笔记本续航。

## 🚀 快速开始

### 1. 环境要求
- Python 3.8+（Windows 7 用户推荐 3.8.10）
- 依赖包：`openai`, `httpx`, `requests`, `h2`（可选，启用 HTTP/2）
- 安装依赖：
```bash
pip install openai httpx requests
```

### 2. 运行
```bash
python chat2.py
```
首次运行会自动创建 `chat_history.json`、`prompt_templates.json`、`chat_config.json`。

### 3. 配置 API Key
三种方式任选：
- 在 **网页版设置面板** 中填写（推荐，无需重启）
- 设置 **环境变量**（厂商专用，如 `DEEPSEEK_API_KEY`）或通用 `CHAT_API_KEY`
- 编辑 `chat_config.json` 或修改脚本顶部的 `API_KEY` 变量

### 4. 启动网页版（可选）
默认自动启动（`http://127.0.0.1:8080`），在 CLI 中输入 `web` 命令即可在浏览器中打开。

## 🌐 网页版（Beta）

网页版提供可视化交互，与 CLI 完全共享 **对话历史、会话、配置、统计**。  
- **地址**：默认 `http://127.0.0.1:8080`（可自定义 `WEB_HOST` / `WEB_PORT`）
- **主要功能**：
  - 流式输出回复，支持思考链展示
  - 消息编辑/删除（右键或按钮）
  - 会话切换、新建、重命名、复制、删除
  - 系统提示词与温度设置
  - API Key / Base URL / 模型 即时填写，即时生效
  - 提示词模板应用与管理
  - 对话搜索（在当前已加载消息中高亮关键词）
  - 导出（Markdown / JSON）和导入（JSON / Markdown）
  - 硬件状态栏、上下文占用进度条、低功耗提示
  - 自动重连与断线重试
  - 夜间/日间主题切换、字号调节、输入历史（上下键）
- **弱机优化**：低内存/低核数时自动降低历史加载条数（100~200条），减少 DOM 节点，延长轮询间隔。

> 网页版可通过命令行参数 `--web-only` 仅启动网页服务，或 `--no-web` 关闭网页版。

## ⚙️ 配置管理

程序使用三个 JSON 文件管理配置与数据：

| 文件 | 用途 |
|------|------|
| `chat_history.json` | 存储所有会话（含消息、系统提示词、温度、用量等） |
| `chat_config.json` | 存储网页版设置的 API Key、Base URL、模型（运行时覆盖代码配置） |
| `prompt_templates.json` | 存储用户自定义提示词模板（内置预置模板自动创建） |

**配置优先级**（从高到低）：
1. 网页版设置面板（写入 `chat_config.json`）
2. 环境变量（厂商专用如 `DEEPSEEK_API_KEY`）
3. 脚本顶部的 `API_KEY`、`BASE_URL`、`MODEL` 变量
4. 通用环境变量 `CHAT_API_KEY`

启动时会自动加载 `chat_config.json`，若不存在则使用脚本默认值。

## 🧠 高级功能详解

### 自动上下文裁剪（Auto Trim）
当累计 token 数超过 **有效阈值**（取配置上限、厂商窗口 90%、可用内存自适应值三者最小值）时，程序自动触发裁剪：  
- 若开启 `SUMMARIZE_ON_TRIM`（默认开启），调用 AI 将最早的一批消息压缩成摘要（`system` 角色）保留在上下文中，保留关键事实与结论。
- 否则直接删除最早的消息。  
该机制使得 **理论上支持无限长度对话**，且不会超出模型窗口限制。

### 硬件自适应调优
程序在启动时检测：
- CPU 核数、主频、架构
- 物理内存大小（并扣除系统预留）
- GPU 型号与显存（通过 `nvidia-smi` 或 `torch`）
- 磁盘剩余空间
- 电源状态（电池/交流）
- 是否 32 位系统（内存上限 3.2GB）

根据检测结果自动调整：
- HTTP 连接池大小（`max_connections`）
- 网页并发线程数（`_web_threads`）
- 自动保存频率（`_SAVE_EVERY`）
- 上下文裁剪内存上限（每 GB 可用内存约分配 96k token）
- 网页历史加载条数（低内存模式 100 条）
- 弱机时关闭 ANSI 彩色输出、降低 gzip 压缩等级

### 思考链（Reasoning）
对于支持思考链的厂商（如 DeepSeek），开启 `thinking` 模式后，模型会在正式回复前输出内部推理过程。  
CLI 中通过 `thinking` 命令开关，`level` 命令调整详细程度（low/medium/high/max）。  
网页版通过复选框和下拉菜单控制。思考链内容以折叠形式（网页）或暗色文字（CLI）显示，不影响最终回复。

### 输入历史与多行输入
- CLI 支持行尾输入 `\` 续行，方便粘贴多行代码。
- 网页版支持 Shift+Enter 换行，Enter 发送，上下键浏览输入历史（本地存储）。

### 余额查询
仅 DeepSeek 官方 API 支持 `/user/balance` 接口，可查询赠送余额与充值余额。

## 🏗️ 技术架构概述

- **核心对话引擎**：基于 OpenAI SDK 的异步流式调用，支持 `stream_options.include_usage` 获取 token 统计。
- **网络层**：使用 `httpx` 客户端，开启 HTTP/2 复用（若 `h2` 包已安装），连接池自适应，TCP_NODELAY 降低延迟。
- **并发控制**：对话锁（`_chat_lock`）保证 CLI 与网页版串行处理回合；网页服务器使用 `ThreadingHTTPServer`，限制最大并发线程数。
- **存储**：对话存档以 JSON 格式原子写入，使用内存缓存 + 文件 mtime 缓存避免频繁读盘；大文件自动用紧凑格式（无缩进）节省空间。
- **流式渲染**：CLI 使用表格感知打印机（`TableAwarePrinter`），自动修复 Markdown 表格对齐；网页版使用 rAF 合并渲染，长回复不卡界面。
- **错误恢复**：请求失败自动重试（指数退避 + 抖动），支持 Retry-After；断线自动重试（网页端），避免重复消息。
- **跨平台兼容**：Windows（包括 Win7/8）、Linux、macOS 均支持；针对 Win7 禁用 ANSI 转义，确保显示正常。

## ❓ 常见问题与注意事项

1. **API Key 未配置时程序会退出吗？**  
   不会。程序会给出提示并引导你打开网页版设置面板填写，填写后立即生效，无需重启。

2. **如何切换本地 Ollama 模型？**  
   输入 `provider ollama`，然后 `model <模型名>`（如 `qwen2.5:7b`）。网页版可通过一键切换按钮（检测到 Ollama 时出现）。

3. **对话历史文件过大怎么办？**  
   程序自动采用紧凑 JSON 格式（超过 1MB 时），并保留 `.bak` 备份。你也可以手动删除 `chat_history.json` 重新开始。

4. **网页版无法访问？**  
   检查防火墙是否允许 `8080` 端口，或修改 `WEB_HOST` 为 `0.0.0.0` 以允许局域网访问（注意安全）。

5. **32 位 Python 内存限制**  
   程序会检测到 32 位系统并将可用内存封顶为 3.2GB，自动降低上下文上限，防止内存溢出。

6. **电池供电时自动降频**  
   检测到笔记本使用电池时，后台轮询间隔延长，保存频率降低，节省电量。
